# TPC 域壁路径编辑器

在本机浏览器中点击域壁允许经过的位置，保存节点、连线和相区。编辑器采用本库三角孔晶胞，可导出毫米 DXF 版图。

## 启动

仓库开发环境安装 `.[geometry]` 后运行：

```powershell
python -B -m tpc_editor --workspace "<你的设计目录>"
```

已安装插件不需要将本库全局安装。按 [插件运行环境](../skills/runtime.md) 选择带 `geometry` 的解释器，再运行：

```powershell
python -B "<插件根目录>/scripts/open_path_editor.py" --workspace "<你的设计目录>"
```

启动后报告 URL 并打开浏览器。`--no-browser` 可只启动服务；`--port` 默认由系统分配，避免冲突；`--ready-file <工作区内的状态文件>` 可保存启动 URL。后台运行 Windows 辅助进程时使用隐藏窗口，日志和 ready-file 都放在用户工作目录。

服务仅监听 127.0.0.1，一次启动对应一个编辑会话。关闭页面不会停止服务；用右上角“停止服务”或启动终端里的 Ctrl+C 结束。服务不自动恢复未保存设计；退出前保存 JSON。

## 一次绘制流程

1. 左侧查看晶格常数 a、大小孔边长比、AB/BA 和原点。画布叠加实际孔形及域壁可选点。默认数值是示例，核对后点击“确认晶胞与域壁点”。
2. 在“绘制域壁”模式点击起点、拐点和终点。同一晶格方向上的远点直接连线；非允许方向需增加拐点，程序不自行绕路。
3. 点击“结束本段”或 Esc。再点击已有节点可从此接出分支，也可在别处另起独立路径。已有线段中间的合法点会拆分线段，避免重复叠线。
4. 合流、闭环可连接已有节点；交叉时明确选择连接或保持分离。非格点交叉不能建立节点。“保持分离”是编辑关系，不代表已经得到同层物理隔离。
5. 点击“填 A 相”或“填 B 相”，再点击相区内部。检查栏会列出未分相、悬空路径、相邻同相、无法分配两相、未解决交叉或跨域壁孔。
6. 保存 JSON；它包含晶胞参数快照、域壁节点、连线、路径段及相区，可重新打开编辑。结构图支持 SVG 和 PNG，有问题会标注为草稿。
7. 几何检查通过后，在“导出”中选择“DXF 版图”。`BOUNDARY` 为闭合外边界，`HOLES_A` 和 `HOLES_B` 各自包含对应相区的整孔闭合轮廓，`DOMAIN_WALL` 为域壁参考线。文件使用设计坐标和毫米单位。Python 可调用 `tpc_editor.export.render_dxf(doc)` 获取相同文件的字节。

## 编辑与边界

- “选择”模式可点节点或线段查看真实坐标、晶格间隔与长度；节点可在右侧输入精确 r/c。
- “移动节点”模式可拖动节点；不能保持六方向关系的移动会回退。Delete 删除当前对象；删除共享线段会显示涉及的路径段。
- Ctrl+Z 撤销，Ctrl+Shift+Z 重做；滚轮缩放，空格或中键拖动画布，“适应画布”恢复视野。
- 矩形外边界可输入坐标。手绘边界依次点顶点，再按 Enter 或点击首点闭合；Esc 取消。第一版边界为无孔洞的简单多边形。
- 改边界导致节点越界时保留草稿并标注，不悄悄截断。相区变化后，仅唯一匹配的旧区域保留标签，冲突区域需重新分配。
- 外边缘只保留完整孔。越界孔不放置，支持显示其轮廓并在导出图中记录数量。内部 A/B 域壁跨孔会作为冲突保留，不能靠丢孔掩盖。

## 坐标与证据口径

域壁使用 `TopoPath` 的轴向坐标约定，x = origin_x + (c+r/2)a，y = origin_y + r√3a/2；默认方向为 0°。路径点不等同于孔中心。孔形、朝向和大小规则复用本库 `generate_crystal_holes` 与三角孔几何函数。

AB/BA 表示孔尺寸排列约定，区域 A/B 表示空间分配。路径绘制方向不决定传播方向或相区。任意分支图不一定能形成一致的 A/B 域壁，冲突设计仍可保存为草稿。

“检查通过”只描述当前离线几何规则；结构图不代表真实 CST readback、求解收敛或功分/拓扑性能。未来实际建模前仍须按仓库约定审阅真实参数草图。
