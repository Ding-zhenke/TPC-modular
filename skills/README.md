# TPC skills

Project-local skills live in this `skills/` directory:

- `topological-modeling`: device configuration, geometry, explicit CST adapter use, and evidence levels.
- `topological-schematic`: authoritative parameter-driven drawings and annotation consistency.
- `lattice-paths`: triangular/hexagonal lattice algorithms, paths, phases, clipping, and DXF.

Use `cst-automation` skills for generic CST sessions, modeling API, simulation, and diagnostics. TPC does not copy that generic manual.
